# Apresentação de Produtos CMEX

Este diretório contém arquivos de apresentação em Markdown para os produtos da linha CMEX. As apresentações incluem planos de negócios, análises de mercado, projeções financeiras e estratégias de lançamento.

## Arquivos Disponíveis

- [Consulta Inteligente de NCM](consulta_inteligente_ncm.md) - Apresentação do produto de consulta inteligente de NCM voltado para contadores e escritórios contábeis
- [IA Generativa como Agente](agente_ia_generativo.md) - Apresentação do produto de IA generativa capaz de executar tarefas cotidianas para usuários

## Como Visualizar as Apresentações

Para melhor experiência visual das apresentações, recomendamos:

1. **VSCode com extensão Markdown Preview Enhanced**: Fornece suporte para diagramas Mermaid e formatação avançada

   - Instale a extensão "Markdown Preview Enhanced"
   - Abra o arquivo .md desejado
   - Pressione `Ctrl+Shift+V` (ou `Cmd+Shift+V` no Mac) para visualizar com a renderização completa

2. **GitHub**: Os arquivos podem ser visualizados diretamente no GitHub, que suporta a sintaxe Mermaid para diagramas

3. **Mermaid Live Editor**: Para editar os diagramas individualmente, visite [mermaid.live](https://mermaid.live/)

4. **Converter para Apresentação**: Para apresentações formais, você pode converter os arquivos para slides usando ferramentas como:
   - [Marp](https://marp.app/) - Markdown Presentation Ecosystem
   - [Slidev](https://sli.dev/) - Apresentações para desenvolvedores
   - [Pandoc](https://pandoc.org/) - Para converter para PowerPoint ou outros formatos
